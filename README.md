# KPSS Anki

KPSS'ye hazırlananlar için aralıklı tekrar (SM-2) ile çalışan, tek dosyalık kart çalışma sayfası. React yok, vanilla JS.

Canlı: https://fr0stb1rd.github.io/kpss-anki/

## İçerik

Sorular ilgili hocalara aittir; her destenin sahibi ve kaynakları kart ekranındaki Hakkında tuşunda görünür. Bu proje sadece çalışmayı kolaylaştıran bir arayüzdür.
